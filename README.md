## Статус проєкту

Проєкт перебуває на початковому етапі розробки.

На поточному етапі:
- створено Git-репозиторій;
- сформовано початковий backlog;
- визначено правила роботи з гілками та commits;
- програмна реалізація буде виконуватися у наступних лабораторних роботах.
